# 인스타툰 제작 사양서 v7 — 「오피스 와이프」(1)
## 실제 렌더링 결과 진단 반영: 인물 실루엣 + 컷=물증 + 정량 간결 규칙

> **왜 v7인가**: v6까지의 기획(글)은 문제없었지만, **실제 렌더링한 20장을 보니 그림이 이야기를 못 했습니다.** 여성 3인이 구분 안 되고, 20장 내내 같은 로비·같은 투샷이 반복되고, 화려한 채색이 오히려 정보를 흐렸습니다. 3인 서브에이전트가 이 세 문제를 각각 근본부터 재설계했습니다.
>
> **v6 → v7 핵심 변경**:
> ① **인물 = 실루엣(형태·명도)으로 구분**, 옷 색은 2순위로 강등
> ② **20장 → 14장**, "대사 왕복 컷"을 전부 **"한 컷 = 한 물증"**으로 교체(카톡 캡처, 반지 자국, 방문자 명부, 사원증 등). 배경·프레임을 컷마다 바꿔 talking-heads 제거
> ③ **정량 간결 규칙 신설**(슬라이드 총 글자수 90자 이내, 말풍선 ≤1, 새 시각정보 1개 필수)
> ④ **화려함 예산제**: 담백 컷 : 화려 컷 = 대략 11:3, 화려함은 감정 피크에만
>
> v6/v4에서 그대로 승계: 워크플로우(§⓪ AI=글자없는 그림, 편집조판), 색 팔레트, Pretendard 폰트, 워터마크, 시리즈 제목 「오피스 와이프」(1)(2)(3)(최종).

# 1. 왜 안 읽혔는가 (진단 요약)

레퍼런스가 간결한 이유는 **"텍스트가 짧아서"가 아니라 "그림이 상황을 지고, 텍스트는 대사/감정 하나만 담았기 때문"**입니다. 메커니즘 3가지:
- **M1. 역할 분담**: 그림=Where/Who/When/상황, 텍스트=한마디(대사/감정)만.
- **M2. 컷당 새 시각정보 1개**: 슬라이드가 넘어갈 때마다 장소·물증·표정 중 하나가 반드시 바뀜. 이게 손가락을 다음 장으로 미는 동력.
- **M3. 인물 구분 = 실루엣(형태)**: 상복 실루엣처럼, 색이 아니라 형태로 0.3초 안에 판독.

우리는 세 가지를 전부 반대로 했습니다: 나레이션이 상황을 설명(M1 위반), 20장 내내 같은 로비·같은 투샷(M2 위반), 인물 구분을 옷 색에만 의존(M3 위반). **v7은 이 세 가지를 되돌리는 작업입니다.**

# 2. 캐릭터 — 실루엣 우선 재설계 (§A-7 전면 교체)

> 원칙: 옷 색은 2순위. **헤어 길이·명도·안경·동반소품**으로 실루엣만으로 구분한다. 헤어 명도 사다리(흑백에서도 갈리게): 수연 15% ▸ 민재 25% ▸ 지현 35% ▸ 아내 60%.

| 인물 | 헤어(형태·색·명도) | 앵커 소품 | 체형·자세 | 옷(2순위 색) | 실루엣 한 줄 |
|---|---|---|---|---|---|
| **수연**(화자) | 턱선 일자단발+일자앞머리, 순검정 `#111`·명도15% | **사원증 랜야드** + 늘 스마트폰 | 소형·다부짐 | 네이비 블라우스 `#2E3A4A` | 새까만 사각헬멧+가슴 랜야드선 — **화면 최암·최소·최각** |
| **지현 팀장** | 낮은 시뇽(어깨에 머리카락 0), 애쉬브라운 `#6B5E52`·명도35% | **검정 사각 뿔테 안경**(유일 착용자) | 장신·마름·칼각어깨·꼿꼿 | 차콜/버건디 블레이저 | 매끈한 묶음머리+안경+칼각어깨 세로기둥 |
| **민재 아내** | 가슴아래 긴 웨이브, 밝은웜브라운 `#B08D5B`·명도60% | **아이 손** + 종이 쇼핑백 | 부드러운 둥근어깨 | 크림/카멜 니트+롱스커트(**평상복**, 정장 아님) | 크고 밝은 웨이브 갈기+옆의 작은 아이 — **최명·A자** |
| **강민재** | 투블럭+다운앞머리, 다크브라운 `#3A2E27`·명도25% (※기존 검정→다크브라운으로 하향, 수연이 순검정 독점) | 손목시계 / 안경 없음 | 슬림·왜소·좁은어깨 | 하늘색 셔츠+회색 니트조끼(레이어드) | 마른 남자+조끼 레이어 몸통 — 유일 청년남 |
| **아이**(5세) | 바가지단발·둥근머리 | 멜빵바지+공룡인형 | 어른 허리높이 | 무관 | 아내 옆 미니 원형 실루엣 |
| **부장**(2편훅) | M자 벗겨짐+반짝 정수리 | 넥타이만(재킷X·소매롤업)+통화폰 | 중년·배불뚝 | 무관 | 대머리 배불뚝 아저씨 — 완전 다른 계열 |
| 동료A/B/C | 리드3인과 안 겹침(짧은포니/남자각진/중단발파마) | — | 평범 | 무채색 | 군중=블러(밝기-12%·채도-20%), 선명 인물 ≤2 |

**락 규칙**: 수연=화면 유일 순검정(민재는 다크브라운으로 하향 조정) / 안경은 지현 전용 / 작은 아이 동반=아내 그룹 확정.

**검증 게이트(제작 필수)**: 완성 컷을 **150px 축소 + 흑백 + 블러8px** 처리해 리드 3인(수연·지현·아내) 실루엣이 갈리는지 확인. 옷색 라벨 가리고 5초 안에 식별되면 통과, 안 되면 재작업.

### AI 생성 일관성 파이프라인
- **참조시트**: 인물별 정면/¾측면/전신 턴어라운드 + 표정 3종(평상/놀람/굳음)을 회색배경 1장에, **seed 고정 후 본편 생성**(v4 §⓪ 승계).
- **일관성 기법**: SD 권장 — 인물당 LoRA(15~20장 학습) + IP-Adapter FaceID + 고정 seed. MJ 대안 — `--cref` + `--cw 100`, 2인 컷은 개별 생성 후 합성.
- **인물별 고정 영문 프롬프트**(매 컷 해당 인물 문장 그대로 삽입):
  - 수연: `jet-black blunt chin-length bob, straight blunt bangs, helmet-shaped, NO loose strands, petite compact build, navy blouse, office lanyard ID badge, holding smartphone` / neg: `brown/long/wavy hair, glasses`
  - 지현: `ash-brown hair pulled back tight into low bun, NO hair on shoulders, thin black rectangular glasses, tall slim sharp squared shoulders, charcoal blazer` / neg: `loose/long hair, no glasses, bangs`
  - 아내: `very long light warm-brown wavy hair past chest, big soft A-shape volume, round face, cream/camel casual knit and long skirt (not a suit), holding child's hand and paper shopping bag` / neg: `short/tied hair, glasses, blazer/suit`
  - 민재: `slim narrow shoulders, dark-brown two-block haircut soft down fringe, NO glasses, light-blue shirt under grey knit vest, wristwatch` / neg: `glasses, broad build, black hair`
- **전역 네거티브**: `three similar women, same face, identical hairstyle, hair color drift, face bleeding between characters`
- **공통 스타일 접미**: v4 §A-8 COMPOSITION 블록(lower-third 앵커, 상단 헤드룸, 미디엄 투샷) 그대로 유지.

# 3. 정량 간결 규칙 (신설 — 모든 컷 필수 게이트)

| 항목 | 상한 |
|---|---|
| 나레이션 띠 | 최대 2줄, **공백포함 40자 이내**. 상황설명형 문장 금지(그림이 진다) |
| 컷당 말풍선 | **최대 1개** (2인 대화는 컷1/컷2로 분리하거나 다음 슬라이드로) |
| 말풍선 1개 | 최대 35자, 2줄 |
| 속마음 구름 | 슬라이드당 최대 1개, **1편 전체 4개 이하** |
| 슬라이드 총 글자수 | 나레이션+말풍선 합산 **90자 이내** |
| 컷당 시각정보 | **새로운 시각 사실 1개 필수**(새 장소/새 물증/새 인물/표정 급변 중 하나). 직전 컷과 배경·구도 동일 금지 |
| 시각 초점 | 컷당 **1곳**만 고채도·고디테일, 나머지 저채도 |
| 선명 인물 | 군중 컷 **≤2**(화자만), 나머지 블러 |
| 레이아웃 예측성 | 표준형 80%+, 특수(강조·카드·밴드) 1편 합계 4장 이내 |

**화려함 예산제**: 담백 컷 : 화려 컷 ≈ **11 : 3**(총 14장 기준). 화려함(풀채색·강조 대형컷)은 감정 피크 3곳에만 — ⓐ아내 등장(리빌) ⓑ지현 커피 쏟음(충격) ⓒ수연 죄책감(거울).

# 4. 14장 비트시트 — "한 컷 = 한 물증"

> 표기: 장소/프레임이 컷마다 반드시 바뀜(연속 2컷 동일 프레임 없음). **[담백]/[화려]** 표기로 채색 예산 명시.

### 【세팅 · 컷1~3】

**C1 — 소문의 출처 (화면 인서트) [담백]**
- 비주얼: **스마트폰 단톡방 화면이 프레임 전체.** 수연 프로필 사진 옆 메시지 "팀장이 막내 꼬셨대ㄷㄷ". 뒤로 수연 손·옆얼굴 살짝.
- [나] "소문을 제일 크게 옮긴 건, 나였다." (22자)
- 목적: 화자=소문원 확정. 물증(카톡 UI)으로 시작, talking-heads 아님.

**C2 — 싱글남 데스크 (오브젝트 클로즈업) [담백]**
- 비주얼: 민재 책상. 가족사진 0, 컵라면·피규어뿐인 '혼자 사는 티'. 도시락 건네는 수연 손이 프레임 안으로.
- 말풍선(민재): "저 아직 혼자가 편해요~" (거짓 씨앗)
- 목적: '미혼' 못박기 + **반지 자국 없는 왼손**(→C7에서 회수) 앵커 심기.

**C3 — 탕비실 문틈 (OTS·훔쳐보기) [담백]**
- 비주얼: 수연 시점, 문틈 너머 민재·지현이 커피 들고 가까이 선 뒷모습. **지현 왼손 결혼반지 반짝.**
- 말풍선(동료): "유부녀가 막내를 넘봐? 애까지 있으면서." **[마무리 밴드]** "팀장님은 끝까지 해명하지 않았다."
- 목적: 지현=유부녀 못박기(반지) + 소문의 '근거 정황' 시각화 + 클리프행어.

### 【접근·리빌 · 컷4~8】

**C4 — 방문자 명부 (오브젝트 인서트) [담백]**
- 비주얼: 로비 안내데스크 위 방문자 명부 손글씨 클로즈업 — "방문: 강민재 / 관계: 가족", 옆에 아이 낙서.
- [나] "미혼이라던 사람에게, 가족이 찾아왔다." (22자) **[마무리 밴드로 클리프행어]**
- 목적: 균열의 시작. 대사 없이 물증(명부)만으로.

**C5 — 엘리베이터 거울 (반사) [담백]**
- 비주얼: 엘베 거울에 비친 민재. 식은땀, 넥타이 만지는 손, 내려가는 층수 표시등.
- 속마음(수연): "나를 말리고 싶어 하는 얼굴이었다."
- 목적: 같은 인물도 새 구도(거울)로. 심리를 얼굴 대신 반사로.

**C6 — 유리문 역광 → 리빌 (강조 대형) [화려 ⓐ]**
- 비주얼: 로비 입구, 역광 실루엣이 풀리며 **아내 정면 미소 + 옆 아이가 든 가족사진 액자**(민재+아내+아이).
- 말풍선(아내): "저, 강민재 씨 아내예요." (12자)
- 목적: 첫 충격. 실루엣→리빌 연출로 등장의 무게. 표지 대사 회수.

**C7 — 로비 바닥 (로우앵글·콜백) [담백]**
- 비주얼: 아이가 달려와 민재 다리를 붙잡는 로우앵글. 민재 굳은 얼굴 + **왼손 무명지의 하얀 반지 자국**(C2 회수).
- 말풍선(아이): "아빠!!" / 민재: "…네가 왜 여기…"
- 목적: 관계 확정 + 시각적 콜백(반지 자국)으로 거짓말 증명.

**C8 — 지현의 충격 (강조 대형·물리적 표현) [화려 ⓑ]**
- 비주얼: 지현 얼굴 하얗게 질림, **손의 종이컵 커피가 기울어 바닥에 한 방울 떨어지는 순간.**
- 속마음(수연): "팀장님은 저 여자가 아니라 '민재 씨'를 아는 얼굴이었다."
- 목적: 충격을 대사가 아니라 사물의 움직임(쏟아지는 커피)으로.

### 【진실 물증 · 컷9~11】

**C9 — 지현의 폰 화면 (카톡 캡처, C1과 대칭 포맷) [담백]**
- 비주얼: 폰 화면 클로즈업 — 민재 카톡 "나 이혼했어. 이제 같이 있어도 돼."
- 말풍선(지현): "…이혼했다고, 분명히 이렇게 보냈어요." (18자)
- 목적: 거짓말의 물증. C1과 같은 '화면 포맷'으로 대칭 → 그림만 봐도 "말이 뒤집힌다"가 읽힘.

**C10 — 두 폰 대조 (손 클로즈업) [담백]**
- 비주얼: 두 손이 폰을 나란히 든 클로즈업. 아내 폰=지난 주말 가족 셀카, 지현 폰=C9 카톡(같은 날짜대).
- 말풍선(아내): "저흰 지난 주말에도 같이 있었는데요." (17자)
- 목적: 시간표 충돌을 그림(날짜)으로. 두 여자가 서로의 진실을 확인.

**C11 — 떨어진 사원증 (상징 오브젝트·민재 프레임 배제) [담백]**
- 비주얼: 두 여자가 마주 섬, 가운데 바닥에 **떨어진 민재의 사원증**. 민재는 등만/프레임 밖.
- 말풍선(아내): "그럼 우리 둘 다 속은 거네요." / 지현: "…저도, 몰랐어요."
- 목적: 가해자 배제 구도로 "누구에게 마이크를 주는가"를 시각화. 여론 역전의 시작.

### 【여파 · 컷12~14 (늘리지 않음)】

**C12 — 명대사 카드 [담백/타이포]**
- 인물 없음, 어두운 로비 실루엣 위 대형 타이포: **"가해자인 줄 알았던 사람이 / 사실은, 가장 크게 속은 사람이었다."**
- 목적: 저장·공유 유발. 1편 1장만.

**C13 — 화장실 거울 속 수연 (강조·콜백) [화려 ⓒ]**
- 비주얼: 회사 화장실 거울 속 수연. 손엔 **C1의 단톡방 화면을 다시 켠 폰**(콜백).
- 속마음(수연): "제일 앞장서 욕한 내가, 제일 부끄러웠다." (핵심, SemiBold)
- 목적: 새 장소(화장실)로 전환 + C1 회수. 화자 죄책감 정점, 화려함 예산 3번째.

**C14 — 법인카드 훅 + CTA (새 장소) [담백]**
- 비주얼: 복도/주차장, 저만치 부장이 통화. **폰 화면에 법인카드 앱 — 민재 이름 옆 빨간 금액.**
- 말풍선(부장): "민재 걔 법인카드… 지금 확인해 봐." **[마무리 밴드]** "그리고 이 일은, 여기서 끝이 아니었다."
- CTA: "🔖 2편 놓치지 않으려면 팔로우 — 매주 화·금 밤 9시" / "「오피스 와이프」(2)에서 계속됩니다" / 픽션 고지.

**표지(C0)**: 로비, 유리문 역광 실루엣의 아내+아이(작게 리빌 전 단계) / [좌]수연 관찰자 옆얼굴(까만 단발로 즉시 식별). 하단 캡션: "모두가 팀장님을 욕하던 날, / 진짜 이야기는 따로 있었다"

**프레임 로테이션 확인**: 폰화면→데스크→탕비실문틈→안내데스크→엘베거울→유리문리빌→로비바닥로우앵글→로비뒤편→폰화면→손클로즈업→로비바닥오브젝트→타이포카드→화장실거울→복도. **연속 2컷 동일 프레임 없음.**

# 5. 완결 판단 · 분량 근거

- **14장 = v6(20장) 대비 6장 압축.** 이유: 대사 왕복형 talking-heads(구 S8·S9·S15·S16 등)를 물증 컷으로 흡수 — 장수는 줄었지만 그림 정보량은 오히려 늘어남(각 컷이 서로 다른 물증).
- **1편 완결 + 법인카드는 2편 훅.** C4(방문자 명부)~C11(사원증)이 "정체 밝혀지는 30분"의 단일 실시간이라는 취지는 유지하되, **한 프레임에 고정하지 않고** 명부→엘베→유리문→바닥→폰으로 시선을 이동시켜 실시간감을 오히려 강화.
- **분할 금지 구간**: C6(아내 등장)~C11(둘 다 속음) 사이는 끊지 않는다.
- **릴스**: 14장이면 물증 컷 각 3~4초로 40~48초, 정보 밀도·스크롤 유지 최적 구간.
