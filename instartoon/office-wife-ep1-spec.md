# 인스타툰 제작 사양서 v6 — 「오피스 와이프」(1)
## v4 기반 · 10→20장 확장 · 이해도 최우선

> **방향(사용자 확정)**: v5(레이아웃 10종·다편 아크)는 폐기. **v4의 실시간 단일 장면·대사 중심 구조를 유지**하되, 컷을 다채롭게 하기보다 **내용 전달을 최우선**으로. 10장을 최대 20장으로 늘려 충분한 대사·상황으로 이해도를 높인다. 시리즈 제목 **「오피스 와이프」** 확정.
>
> **디자인·스토리 3인 검토 반영**: ①스토리 20장 확장(빌드업 8 + 반전 9 + 마무리 2) ②이해도 감사(관계 세팅·진실 계단·이름표) ③레이아웃 4종 압축(예측 가능성=이해도).
>
> **v4에서 그대로 승계(변경 없음)**: 제작 워크플로우(§⓪ AI=글자 없는 그림만, 편집툴 조판) · 색 팔레트(§A-2) · Pretendard 단일 폰트(§A-3) · 캐릭터 시트(§A-7) · 작화 구도(§A-8, lower-third 앵커+상단 헤드룸+미디엄 투샷) · 워터마크(§A-9). 이 문서는 **바뀐 부분(레이아웃·화자명확화·비트시트)**만 상술한다.

# 1. 레이아웃 — 4종으로 압축 (§A-4 대체)

> **원칙: 예측 가능성 = 이해도.** 독자가 20장을 넘겨도 "다음 대사가 어디 있을지" 알게 한다. 틀은 4종 고정, 확장은 "표준 2단을 더 쓰는 것"으로 흡수. v5의 10종·비대칭·인서트는 전부 폐기. 좌표는 v4 승계.

| 종 | 틀 | 좌표 | 언제 | 비중 |
|---|---|---|---|---|
| **①표준 2단** (주력) | 나레이션 띠 + 컷1 + 컷2 | 띠 y36~186 / 컷1 y200~670 / 컷2 y690~1160 | 기본값. 대화·전개·반응 전부 | 70~75% |
| **②강조 1컷** | 나레이션 띠 + 컷 하나 확대 | 띠 y36~186 / 컷 y200~1160(h960) | **감정 피크 3곳만**: ⓐ아내 등장 ⓑ팀장 창백 ⓒ화자 죄책감. 말풍선 ≤2 | 3장 |
| **③명대사 카드** | 컷2를 대형 타이포 카드 | 컷1 정상 + 컷2 인물없음, 어두운 스크림 `#20232A` 30~40% + 흰글자 Bold 56px 중앙 | 저장·공유용 문장 1개. 1편당 1장 | 1장 |
| **④마무리 밴드** | 컷2 축소 + 이보리 전용 밴드 | 컷2 y690~1050 / 클리어갭 y1050~1065 / **나레이션 밴드 y1065~1160(배경없는 `#EFE9E1`)** | 장을 한 문장으로 닫아 다음으로 밀 때(클리프행어) | 3~4장 |

- **마무리 나레이션은 절대 컷 이미지 위에 얹지 않는다**(이보리 밴드에만). 상단 띠와 마무리 밴드를 한 장에 동시 사용 금지(밴드 장은 상단 띠 1줄로 짧게).
- 진행 카운터 **"N/20"**(위치·크기 v4 그대로).

# 2. 화자 명확화 — 색코딩 없이, 이름표 + 인접 (§A-5 보강)

> v4 §A-5(안전인셋24·헤드룸28%·얼굴회피·사이드락·꼬리·속마음구름) 전부 승계. **말풍선 색코딩은 안 함**(전원 흰 면 `#33475B` 테두리 통일). 아래를 추가한다.

1. **★인물 첫 등장 이름표** — 5명이 나오는 반전물은 이름표가 과잉이 아니라 필수. 각 인물이 **처음 등장하는 컷에 1회만**, 얼굴 근처에 얇은 캡션형 네임태그(Pretendard Medium 20px, `#6E6656`, 대시 접두). 재등장부턴 뺀다.
   - "김수연 · 이 팀 3년차"(화자) / "막내 강민재" / "지현 팀장" / "민재 씨 아내" / "옆 팀 부장님".
2. **화자 인접(1순위)** — 말풍선은 말하는 인물 머리 위 헤드룸에 붙고, 그 인물 얼굴·입이 컷에 보인다. 꼬리가 짧게 입에 닿음. → 좌/우·구도 자유롭게 바꿔도 화자 자명(레이아웃 다양성 최소치와 충돌 없음).
3. **수연 속마음 = 색+꼬리로 묶기** — 화자 수연의 속마음 구름은 **꼬리를 항상 수연 정수리에 확실히** 물린다. 수연은 표지부터 식별색(네이비 `#2E3A4A`) 노출해 "이 속마음의 주인"을 각인.
4. **군중 컷 = 선명 인물 ≤2** — 말하는 사람만 선명, 구경꾼은 블러(밝기-12%·채도-20%). 색 없이도 화자 도드라짐.
5. **한 컷 말풍선 ≤2**(속마음 포함). 초과 시 다음 장으로 분할(20장 여유로 해결) — "정신 사나움"의 최대 원인 차단.
6. **속마음 남발 금지** — 핵심 속마음 4개만 SemiBold 38px(소문 믿음/미혼인데 가족/팀장 하얘짐/제일 부끄러움), 나머지는 나레이션·대사로.

# 3. 인물 소개 설계 (초반 1~6장에 관계를 심는다)

> 이해도 감사 핵심: **소문이 터지기 전에 5명의 "이름표 + 한 줄 역할 + 관계"를 얼굴과 함께 먼저 깐다.** 반전물은 앞 세팅을 생략하면 무너진다.

| 인물 | 심는 장 | 이름표 + 관계 한 줄 |
|---|---|---|
| 수연(화자) | 표지 + S2 | "김수연 · 이 팀 3년차." **독자 시점 = 수연** 확정(표지 관찰자 옆얼굴) |
| 민재 | S3 | "막내 강민재. **미혼이라던** 착한 후배" — '미혼'을 못박아 복선 씨앗 |
| 지현 팀장 | S4 | "지현 팀장. 남편도 아이도 있는, 다들 따르던" — **유부녀 설정을 미리** 깔아야 소문이 성립 |
| 민재↔지현 정황 | S4 | 소문 근거 컷: "요즘 둘이 유독 붙어다녔다" 목격 1컷(진실은 나중) |
| 아내+아이 | S10 | "민재 씨 아내" — 니트색 대비로 수연과 헤어색 안 겹치게 |
| 부장 | S20 | "옆 팀 부장님" — 2편 훅 인물, 이름표 한 줄이면 충분 |

# 4. 20장 비트시트 (레이아웃 타입 + 나레이션 + 말풍선 대사)

> 표기: **[T]** 레이아웃(①②③④) / **[나]** 상단 나레이션 / "대사"(화자[위치]) / (속) 속마음 구름 / **[마무리]** 하단 이보리 밴드. 좌우는 그 장면 내 고정.

### 【기 · 세팅 S1~S6】

**S1 — 표지**
- 제목 **「오피스 와이프」(1)**. 하단 캡션 띠(2줄): "모두가 팀장님을 욕하던 날, / 진짜 이야기는 따로 있었다"
- 일러스트: 회사 로비. [우]낯선 여자+아이 또렷 / **[좌]수연 놀란 옆얼굴(관찰자 시점 확정)** / [중 멀리]지현 굳어 있음
- 말풍선(아내): "저, 강민재 씨 아내인데요." / 픽션 고지 소자

**S2 — 화자 소개** [T①]
- **[나]** "나는 이 팀 3년차 김수연. / 소문이라면, 누구보다 빨랐다."
- 컷1(수연 정면, 동료들과 수다 — **이름표 "김수연 · 3년차"**): 수연[좌]:"야, 그 얘기 들었어? 내가 제일 먼저 알려주는 거야." / 동료A[우]:"언니는 진짜 소식통이라니까ㅋㅋ"
- 컷2(수연 혼자): (속)"그땐 몰랐다. 그 '빠른 입'이 / 누굴 찌르게 될지." ← 20장 여는 예고 훅

**S3 — 민재 소개** [T①]
- **[나]** "강민재. 우리 팀 막내. / 미혼이라 다들 챙겨주던, 착한 후배."
- 컷1(점심, 수연이 도시락 건넴 — **이름표 "막내 강민재"**): 수연[좌]:"민재 씨, 오늘도 혼자 먹어? 이거 같이 먹자." / 민재[우]:"헤헤 감사합니다 선배~"
- 컷2(동료들과): 동료B[우]:"민재 씨는 언제 여친 생겨? 이 착한 걸 아무도 못 데려가네~" / 민재[좌]:"에이, 저 같은 게 무슨~ 아직 혼자가 편해요." ← 거짓말 씨앗

**S4 — 팀장 소개 + 소문 발단** [T①]

- 컷2: 동료C[좌]:"딱 봐도 유부녀가 착한 애 꼬시는 그림이지." / (속)"그 말이 사실인지 아닌지는, / 아무도 확인하지 않았다."

**S5 — 화자가 앞장서 욕함** [T①]
- **[나]** "그 소문을 가장 크게 퍼뜨린 사람은, / 바로 나였다."
- 컷1(수연 흥분): 수연[중]:"진짜 어이없지 않아? 유부녀가 팀 막내를 넘봐? 애까지 있는 사람이." / 동료A[우]:"언니 말 들으니 확실하네…"
- 컷2(지현이 저만치 지나감, 수연 눈 흘김): (속)**"팀장님 얼굴만 봐도 화가 났다. / 나는, 확신하고 있었다."**(SemiBold 핵심)

**S6 — 아무 말 못 하는 팀장(복선)** [T①]
- **[나]** "팀장님은, 아무 변명도 하지 않았다. / 나는 그게 더 뻔뻔해 보였다."
- 컷1: 동료A[좌]:"팀장님은 왜 해명을 안 하실까?" / 수연[우]:"찔리니까 그렇지. 떳떳하면 말을 하겠지."
- 컷2(지현 옆모습, 무언가 삼키는 얼굴): (속)"그때 팀장님 표정을, / 나는 완전히 잘못 읽고 있었다." ← 피해자 복선

**S7 — 이상한 전화** [T④ 클리프행어]

**S11 — 아이** [T①]
- **[나]** "여자 옆엔, 다섯 살쯤 된 아이가 있었다."
- 컷1: 아이[중]:"엄마, 아빠 언제 와? 아빠 보고 싶어." / 아내[우]:"곧 올 거야~"

- **[나]** "소문을 들은 사람들이 로비로 모였다. 그중엔, 팀장님도 있었다."

**S15 — 진실 A: 함께 산다** [T①]
- **[나]** "두 여자의 말을 나란히 놓자, 우리가 알던 민재 씨는 없었다."

- 컷2: 지현[좌]:"…지방에, 가족이…" / (속)"팀장님은, 이 사실을 지금 처음 듣는 얼굴이었다."

# 5. 완결 판단 · 과잉설명 주의

- **S1~S20을 1편으로 완결**, 법인카드는 (2)편 훅으로만. 20장 전체가 "로비에서 정체가 밝혀지는 그 30분"의 단일 실시간 장면 → 중간에서 끊지 않는다. **S10(아내 등장)~S17(둘 다 속음) 사이는 절대 분할 금지**(반전은 한 편 안에 완주).
- **분량 배분**: 빌드업 S2~S9(8장) → 진실 계단 S10~S17(8장) → 여파 S18~S20(3장). **반전 이후는 짧게** 유지해 늘어짐 방지.
- **과잉설명 금지**: 아이 심리·회사 배경·팀장 결혼 내막 상술·법인카드 액수 금지. 민재는 **침묵**(변명 대사 금지 — 가해자에게 마이크 주면 화자 죄책감 축이 흐려짐). 픽션 고지는 표지·S20·캡션 3곳만.
